# Site da Dra. Gabrielle Ferreira

Projeto em Next.js e React pronto para GitHub e Vercel.

## Publicação na Vercel

1. Envie todo o conteúdo desta pasta para a raiz de um repositório no GitHub.
2. Na Vercel, escolha **Add New > Project**.
3. Importe o repositório.
4. Confirme o framework **Next.js** e clique em **Deploy**.
5. Depois da publicação, acesse **Settings > Domains** para conectar o domínio próprio.

## Execução local opcional

```bash
npm install
npm run dev
```

## Produção

```bash
npm install
npm run build
npm start
```

O conteúdo principal fica em `app/page.tsx`, o estilo em `app/globals.css` e as imagens em `public/images`.
